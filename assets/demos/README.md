# Gameplay previews

These previews are excerpts from the [GameScaling project page](https://gamescaling.github.io/#demo-frontier), showing **GameScaling-9B-S3** in the **time-paused** setting. Each README card links to its complete source recording.

The animated WebP files are 400 × 225 pixels at 10 fps, with the source aspect ratio and action overlay preserved. Playback speed is unchanged from the source recording. Most excerpts are 8 seconds; Mine Sugar Cane uses its complete 4.2-second recording. Matching JPEGs provide still images for readers who prefer reduced motion.

[manifest.json](manifest.json) records the source URLs, excerpt times, dimensions, sizes, and SHA-256 hashes. These are individual illustrative rollouts; benchmark averages and comparisons are available on the project page.
